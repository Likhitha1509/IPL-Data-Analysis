# IPL-Data-Analysis
IPL Data Analysis using Python, Pandas, and NumPy with Exploratory Data Analysis (EDA) on IPL match data.
# 🏏 IPL Data Analysis using Python

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Indian Premier League (IPL) matches dataset using Python. The objective is to uncover meaningful insights about team performance, toss decisions, match outcomes, venues, and player achievements using data analysis techniques.

The project demonstrates practical skills in data cleaning, data manipulation, aggregation, and visualization using Python libraries.

---

## 🎯 Objectives

- Analyze IPL match data to identify trends and patterns.
- Perform data cleaning and preprocessing.
- Extract meaningful business insights from the dataset.
- Practice real-world data analysis using Python.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

---

## 📂 Dataset

**File Used**

- `matches.csv`

**Dataset Features**

- Season
- City
- Venue
- Teams
- Toss Winner
- Toss Decision
- Match Winner
- Player of the Match
- Result
- Umpires

---

## 📊 Analysis Performed

The project includes analysis such as:

- Total IPL matches played
- Matches played season-wise
- Most successful IPL teams
- Toss Winner vs Match Winner analysis
- Toss winning percentage
- Most Player of the Match awards
- Venue-wise match distribution
- Winning teams analysis
- Team performance comparison
- Data cleaning and handling missing values

---

## 📈 Key Insights

- Identified the teams with the highest number of victories.
- Calculated how often the toss-winning team also won the match.
- Analyzed match distribution across different seasons and venues.
- Identified players with the highest Player of the Match awards.
- Explored trends in toss decisions and match outcomes.
